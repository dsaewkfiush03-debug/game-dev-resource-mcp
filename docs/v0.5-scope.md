# V0.5 scope

V0.5 expands the verified registry and makes game-development metadata first-class search filters.

## Added search dimensions

- engine
- dimension
- style
- formats
- asset types
- game genres
- animation state

## Content priorities

The verified catalogs now emphasize practical game-development categories: 2D, pixel art, UI, vehicles, characters, environments, audio/interface sounds, shaders and starter/demo projects.

## Safety model

Only original or authoritative sources with verifiable licensing are added. The project stores metadata and canonical links, not mirrored third-party asset files. Repository-level licenses must not be assumed to cover independently licensed bundled assets.
